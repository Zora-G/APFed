# APFed

Implementation of the algorithms published in "APFed: Anti-Poisoning Attacks in
Privacy-Preserving Heterogeneous Federated Learning", IEEE Transactions on
Information Forensics and Security, vol. 18, pp. 5749–5761, 2023.

## Installation

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

`python main.py --help` lists all options.
